## 2. 另一台电脑（另一个网段）

先装 Armada 桌面，走 **加入舰队**。不要在那台机器上创建舰队，不要另起一份 hub。

| # | 动作 | 通过 | 记下 |
| --- | --- | --- | --- |
| 1 | `curl -sS -m 5 http://<en0 的 IPv4>:7380/api/health` | 超时或连不上 | 命令原文和报错。若返回 JSON，网段并未隔离，后面步骤作废 |
| 2 | 打开加入页，等发现列表 | 列表里没有这台中台 | 列表是空，还是出现了别的舰队 |
| 3 | 粘贴中台给的分享链接并加入 | 加入失败，界面说明连不上 | 界面原文。不要重试去改 token |
| 4 | 回到中台看板看侧栏 | 没有这台新电脑 | 有没有新机器名 |

第 1 步已经能连上时：停。记下另一台的默认路由和当时的 `en0` 地址。这种结果说明两台机器路由得到对方的私网地址，不能用来证明跨网。

第 3 步加入成功时：同样停，并写明当时两边的 IPv4。这表示现有局域网加入在这个网段仍可用，不是跨局域网舰队已落地。

## 3. 测完写回本文

在下面填结果。不要粘贴 token 或完整分享链接。

| 项 | 结果 |
| --- | --- |
| 日期 / 另一台电脑名 | 2026-10-12 / `MacBook-Pro`（macOS 26.5.2） |
| 另一台 IPv4 的前三段 | `192.168.2` |
| 中台开测时的 `en0` 地址 | `192.168.1.196/23`。计划里的 `192.168.31.17` 已过期 |
| 第 1 步健康检查 | 双方到对方地址的路由都改到局域网网卡（另一台网关 `192.168.2.1`，中台回程网关 `192.168.0.1`）之后，TCP 在 2 秒内超时：`TimeoutError timed out`。此前流量进 `utun4` / `198.18.0.1` 时，本机会立刻接受 TCP，`curl` 5 秒且 0 字节，那一次不能当作私网结果 |
| 第 2 步发现列表 | 未发现开放舰队，可粘贴链接加入 |
| 第 3 步加入界面原文 | 路由在 `en0` 之后没有再加入。隧道未拆开时界面曾是「7380 被其他程序占用」，该次作废 |
| 第 4 步侧栏 | 没有因这次私网加入出现的新在线机器 |
| 结论 | 私网 TCP 不通。该条件下没有执行加入，不能记为未隔离或私网加入成功。这也不表示经中转加入已完成 |
